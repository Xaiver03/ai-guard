# AI Guard 书签管理功能 - 用户旅程文档

## 1. 用户画像

### 主要用户群体

**开发者 / AI 工具重度使用者**
- 年龄：25-40 岁
- 职业：软件工程师、产品经理、技术创业者
- 特征：
  - 每天使用多个浏览器（Chrome、Edge、Safari、Dia 等）
  - 收藏大量技术文档、AI 工具、开发资源
  - 书签数量：200-1000+ 个
  - 痛点：书签杂乱无章、重复收藏、找不到需要的链接

**典型用户场景**
- 场景 1：开发者收藏了大量 AI 工具和文档，但分类混乱
- 场景 2：跨浏览器工作，书签分散在不同浏览器中
- 场景 3：书签积累多年，有大量失效链接和重复项
- 场景 4：需要快速找到某个工具或文档，但记不清在哪个文件夹

## 2. 核心价值主张

**为什么用户需要 AI Guard 的书签管理？**

1. **AI 驱动的智能分类** - 自动识别和分类 AI 相关内容
2. **多浏览器统一管理** - 一个界面管理所有浏览器书签
3. **问题自动检测** - 发现重复、失效、命名不规范的书签
4. **零学习成本** - 基于 Web 的直观界面，无需安装额外软件
5. **数据安全** - 所有处理在本地完成，不上传云端

## 3. 用户旅程地图

### 阶段 1：发现与安装

**触发点**
- 用户在使用 AI Guard 监控系统资源时，发现菜单栏有"书签管理"功能
- 或在主页看到"书签管理"导航按钮

**用户行为**
1. 点击"书签管理"按钮
2. 浏览器打开 http://localhost:8765/bookmarks.html
3. 看到欢迎页面和功能介绍

**用户期望**
- 快速了解功能
- 看到支持哪些浏览器
- 知道如何开始使用

**设计要点**
- 首屏显示清晰的功能说明
- 突出显示支持的浏览器图标
- 提供"快速开始"引导

### 阶段 2：选择浏览器

**用户行为**
1. 查看自动检测到的浏览器列表
2. 点击想要管理的浏览器卡片
3. 等待书签加载

**用户期望**
- 快速识别已安装的浏览器
- 看到每个浏览器的书签数量预览
- 加载速度快（< 2 秒）

**设计要点**
- 浏览器卡片显示：图标、名称、书签数量、最后更新时间
- 未安装的浏览器显示为灰色不可点击
- 加载时显示进度指示器

**潜在问题**
- Safari 需要额外权限 → 提供清晰的权限配置指引
- 书签文件路径不标准 → 提供手动选择文件的选项

### 阶段 3：查看书签概览

**用户行为**
1. 查看书签统计信息（总数、文件夹数、域名数）
2. 浏览书签列表（默认显示前 100 个）
3. 查看文件夹结构

**用户期望**
- 快速了解书签整体情况
- 看到书签的组织结构
- 识别潜在问题

**设计要点**
- 顶部显示关键指标卡片
- 书签列表支持折叠/展开文件夹
- 显示书签的元信息（添加时间、访问次数等）

**用户心理**
- "我的书签这么多了？"
- "原来有这么多重复的"
- "这个文件夹太乱了"

### 阶段 4：分析问题

**用户行为**
1. 点击"分析"按钮
2. 等待分析完成（通常 < 5 秒）
3. 查看问题报告

**用户期望**
- 快速发现书签中的问题
- 问题分类清晰（重复、失效、命名不规范等）
- 提供具体的问题位置和建议

**设计要点**
- 问题按严重程度分级：
  - 严重（红色）：重复书签、失效链接
  - 警告（黄色）：URL 过长、命名不规范
  - 建议（蓝色）：大型文件夹、未分类书签
- 每个问题显示：
  - 问题描述
  - 影响的书签数量
  - 具体书签列表
  - 建议的解决方案

**用户决策**
- "这些重复的可以删除"
- "这个文件夹确实需要细分"
- "这些 URL 参数可以清理"

### 阶段 5：AI 智能分类

**用户行为**
1. 点击"AI 分类"按钮
2. 等待 AI 分析（10-30 秒，取决于书签数量）
3. 查看 AI 提供的分类建议

**用户期望**
- AI 能理解书签内容
- 提供合理的分类方案
- 给出具体的整理建议

**设计要点**
- 分析前显示：
  - 将分析的书签数量（默认 50 个）
  - 预计消耗的 token 数量
  - 预计费用（如果有）
- 分析结果显示：
  - 推荐的文件夹结构
  - 每个分类的书签列表
  - 整理优先级建议
- 提供"应用分类"按钮（未来功能）

**潜在问题**
- AI 未配置 → 显示配置指引，链接到 Claude Code 设置
- 分析超时 → 提供重试选项，建议减少分析数量
- 分类不准确 → 提供反馈机制

### 阶段 6：搜索书签

**用户行为**
1. 在搜索框输入关键词
2. 查看搜索结果
3. 点击书签打开链接

**用户期望**
- 实时搜索（输入即搜索）
- 支持模糊匹配
- 高亮显示匹配内容

**设计要点**
- 搜索范围：书签名称、URL、文件夹名称
- 搜索结果显示：
  - 匹配的书签
  - 所在文件夹路径
  - 高亮匹配的关键词
- 支持快捷键（Cmd+F）

**用户场景**
- "我记得收藏过一个 Claude API 的文档"
- "那个 GitHub 项目叫什么来着"
- "找一下所有关于 Python 的书签"

### 阶段 7：导出书签

**用户行为**
1. 点击"导出"按钮
2. 选择导出格式（JSON / HTML / CSV）
3. 下载导出文件

**用户期望**
- 快速导出
- 支持多种格式
- 文件可以在其他工具中使用

**设计要点**
- 导出格式说明：
  - JSON：结构化数据，便于程序处理
  - HTML：标准书签格式，可导入其他浏览器
  - CSV：表格数据，便于 Excel 分析
- 导出选项：
  - 导出全部 / 导出当前文件夹
  - 包含 / 不包含子文件夹
- 导出后提示文件保存位置

**用户场景**
- 备份书签
- 迁移到其他浏览器
- 用 Excel 分析书签数据
- 分享书签给团队

## 4. 关键用户流程

### 流程 1：首次使用（新用户）

```
1. 打开 AI Guard → 点击"书签管理"
2. 看到欢迎页面 → 了解功能
3. 选择浏览器（如 Chrome）
4. 查看书签概览 → 发现有 500 个书签
5. 点击"分析" → 发现 20 个重复书签
6. 点击"AI 分类" → 获得整理建议
7. 导出书签备份
```

**关键成功指标**
- 从打开到完成首次分析 < 2 分钟
- 用户能理解分析结果
- 用户愿意继续使用

### 流程 2：日常使用（老用户）

```
1. 打开书签管理
2. 选择浏览器
3. 搜索特定书签
4. 打开链接
```

**关键成功指标**
- 从打开到找到书签 < 30 秒
- 搜索准确率 > 90%

### 流程 3：深度整理（高级用户）

```
1. 选择浏览器
2. 分析问题 → 查看详细报告
3. AI 分类 → 获得整理方案
4. 手动调整分类（在浏览器中）
5. 重新分析 → 验证改进效果
6. 导出备份
```

**关键成功指标**
- 整理后问题数量减少 > 50%
- 用户满意度 > 4/5

## 5. 用户痛点与解决方案

### 痛点 1：书签太多，找不到想要的

**解决方案**
- 强大的搜索功能
- AI 智能分类建议
- 问题检测（大型文件夹提醒）

### 痛点 2：不知道书签有什么问题

**解决方案**
- 自动分析功能
- 问题分级显示
- 具体的修复建议

### 痛点 3：跨浏览器管理麻烦

**解决方案**
- 统一界面管理多个浏览器
- 一键切换浏览器
- 未来支持跨浏览器同步

### 痛点 4：不知道如何整理

**解决方案**
- AI 提供分类建议
- 显示最佳实践
- 提供整理模板

### 痛点 5：担心数据安全

**解决方案**
- 所有处理在本地完成
- 不修改原始书签文件
- 明确说明 AI 分析时发送的数据
