# AI Guard — Claude 统计页面规范

> 继承自 `design-system/MASTER.md`，以下为 usage.html 特有规则。

## 特有组件

### 时间范围选择器

- 预设：今日 / 昨天 / 近三天 / 本周 / 本月 / 全部
- 自定义日期范围：日期选择器
- 激活态：`background: var(--accent-blue)` 按钮

### 统计卡片布局

- 第一行：4 个主要卡片（Token总数/费用/活跃天/模型数）
- 第二行：5 个次要卡片（输入/输出/缓存写/缓存读/请求数）
- 数值用 `font-variant-numeric: tabular-nums`
- 支持紧凑（1.2M）/ 完整（1,234,567）格式切换

### 图表区域（2 列）

- Token 趋势图 + 费用趋势图
- 高度：280px（`.chart-wrap-lg`）
- 支持折线图 / 柱状图切换

### 模型分布

- Donut 图：高度 240px（`.chart-wrap-donut`）
- 图例点击可切换系列可见性
- 右侧详细表格补充无障碍访问

### 定价配置页（第二个 Tab）

- 模型定价表：可编辑单元格
- 添加自定义模型
- 重置定价按钮（带确认对话框）

## 图表颜色（模型分布）

按顺序分配（避免纯红/绿相邻）：
1. `#58a6ff` — claude-sonnet
2. `#3fb950` — claude-haiku
3. `#d29922` — claude-opus（其他模型）
4. `#bc8cff` — 其余
5. `#e3b341` — 更多

## 页面内 Tab

- "数据面板" / "定价配置"
- 样式同 `.nav-tabs` 但作为页面内切换（非导航）
